# homebrew-tap

Homebrew tap for [@pranshugupta54](https://github.com/pranshugupta54)'s apps.

## Hertz

A native macOS menu-bar system monitor — [github.com/pranshugupta54/hertz](https://github.com/pranshugupta54/hertz).

```sh
brew install --cask pranshugupta54/tap/hertz
```

or:

```sh
brew tap pranshugupta54/tap
brew install --cask hertz
```

Hertz keeps itself up to date from GitHub Releases after install.
